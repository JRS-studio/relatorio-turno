# relatorio-turno

Dois projetos neste repositório:

- **Raiz** (`index.html`, `sw.js`, `manifest.webmanifest`): PWA original do Relatório de Turno, com servidor em Google Apps Script e solicitações da operação.
- **`app/`**: app Android novo, independente, só para lançamento das ocorrências e envio do relatório no WhatsApp. Sem servidor, sem internet, sem dados da empresa no código. Veja [`app/README.md`](app/README.md) para gerar e publicar na Play Store.
